Front-End

El desarrollo web front-end es la práctica de convertir datos en una interfaz gráfica para que los usuarios puedan ver e interactuar con la información mediante el uso de tecnologías web en el navegador.

Herramientas y tecnologías

  • HTML.- Estructura fundamental del documento web.
  • CSS.- Controla el aspecto visual, el diseño, la presentación y la adaptación a diferentes pantallas.
  • JavaScript.- Transforma una página estática en una interfaz dinámica e interactiva.
